# دراما العائلة

PWA عربي لمتابعة المسلسلات: الحلقات الجديدة، قائمة المسلسلات، المفضلة، آخر المشاهدات.
كل البيانات الشخصية (مفضلة، تقدم، تنزيلات) في IndexedDB على الجهاز فقط.

## الإضافة إلى الشاشة الرئيسية (iPhone / iPad)
1. افتح الرابط في Safari. 2. زر المشاركة. 3. «إضافة إلى الشاشة الرئيسية».

## الفهرس
`scripts/sync-qesset.mjs` يكتب `data/shows.json` ويعمل كل 30 دقيقة عبر GitHub Actions. الواجهة تقرأ عبر `source.js` فقط.
`?demo=1` يعرض بيانات وهمية لاختبار الواجهة (غير حقيقية).

## تطوير محلي
`node scripts/dev-server.mjs` ثم افتح http://localhost:8123

## تشغيل الحلقات (نتائج اختبار فعلي، 2026-11-10)
- صفحة الحلقة في المصدر تحمل رابط `qesen.net/watch/?post=<base64>` فيه قائمة السيرفرات ومعرّفاتها. تقرأها المزامنة (`resolveServers`) وتخزّنها في `ep.sv` (a=Arab HD، t=Turk، o=OK)، 900 حلقة لكل تشغيل، الأحدث أولًا.
- التطبيق يعرض مشغّل المضيف مباشرة في iframe (بدون صفحة المصدر وإعلاناتها) مع `sandbox` يمنع النوافذ المنبثقة. اختُبر على 3 حلقات حقيقية من التطبيق المنشور: الفيديو يعمل بلا نوافذ منبثقة.
- لا يمكن حفظ الدقيقة ولا التنزيل مع هذه المشغّلات: لا ترسل postMessage، ورابط HLS يُولَّد داخل الـ iframe بتوكن مؤقت (t,s,e) ولا نصل إليه بطريقة مشروعة. لذلك يحفظ التطبيق آخر حلقة وعلامة «تمت المشاهدة».
- OK.ru أعاد «غير متاح للمنطقة» من خادم أمريكي؛ لم يُختبر من جهازك. express (cloud.mail.ru) وRed HD غير مدعومين.
- مسار المشغّل الأصلي (`ep.v` mp4/hls: حفظ كل 5 ثوانٍ، استكمال، تنزيل) جاهز ومُختبر على فيديو تجريبي، ويعمل إن توفّر رابط مباشر.
