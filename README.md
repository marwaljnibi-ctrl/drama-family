# دراما العائلة

PWA عربي لمتابعة المسلسلات: الحلقات الجديدة، قائمة المسلسلات، المفضلة، آخر المشاهدات.
كل البيانات الشخصية (مفضلة، تقدم، تنزيلات) في IndexedDB على الجهاز فقط.

## الإضافة إلى الشاشة الرئيسية (iPhone / iPad)
1. افتح الرابط في Safari. 2. زر المشاركة. 3. «إضافة إلى الشاشة الرئيسية».

## الفهرس
`scripts/sync-qesset.mjs` يكتب `data/shows.json` ويعمل كل 30 دقيقة عبر GitHub Actions. الواجهة تقرأ عبر `source.js` فقط.
`?demo=1` يعرض بيانات وهمية لاختبار الواجهة (غير حقيقية).

## تطوير محلي
`node scripts/dev-server.mjs` ثم افتح http://localhost:8123
